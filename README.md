Learning exercises from the [Boot.dev Learn JavaScript](https://www.boot.dev/courses/learn-javascript) course.

The course focuses on modern JavaScript fundamentals, asynchronous programming, and the JavaScript runtime ecosystem.

## Course Topics

- Variables, comparisons, and functions
- Objects, classes, and prototypes
- Loops and arrays
- Error handling
- Sets and maps
- Promises and async/await
- The event loop
- JavaScript runtimes
- CommonJS and ES modules

## Repository Exercises

- JavaScript strict mode
- Modular JavaScript code
- CommonJS to ES modules migration
- Babel transpilation
- Browser and Node.js execution
- npm dependency management
- Vite bundling
- Command-line application using cowsay

## Getting Started

```bash
npm ci
npm run build
npm start
```
